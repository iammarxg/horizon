# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [v1.0.1] - 2026-09-06

### Changed
- **Universal Browser Footer Guide:** Streamlined the browser bottom footer removal guide to be straightforward, visual, and concise. Enabled across all Chromium browsers (Chrome, Brave, Edge, Opera, etc.) without browser-specific bypasses.
- **Icon Refinements:** Synchronized frosted glass squircle emblem icons across all extension and store assets with zero outer margin padding.

## [v1.0.0] - 2026-09-05

### Added
- **Google Account Switcher:** Direct Google Sign-In with automatic session synchronization (`/u/N/` index routing, display names, and high-res avatar caching).
- **Google Apps Drawer:** Offline bundled 42 Google services with drag-and-drop custom reordering and dynamic account routing.
- **Dynamic Shortcuts:** Custom website shortcuts supporting row and 2-column grid views, drag-and-drop reordering, right-click context editing, and automated favicon resolution.
- **Voice Search Dictation:** Integrated Web Speech API supporting 35 languages and regional dialects, live animated soundwaves, RTL support, extension-origin permission flow, and Brave privacy awareness.
- **Multi-Engine Search Autocomplete:** Real-time query completions for Google, Brave Search, Bing, DuckDuckGo, Qwant, and Yahoo with floating dropdown UI and keyboard navigation.
- **Wallpaper Customization Suite:** 12 curated Unsplash nature wallpapers with smooth crossfading, custom local photo uploads, solid colors, and luminance-adaptive clock/text shading.
- **Glassmorphism UI Themes:** Automatic, dark, and light appearance modes with frosted glass effects and responsive mobile adaptations.
- **Chromium Native Footer Guide:** First-run onboarding modal guiding users to permanently hide Chrome's bottom toolbar via the right-click menu, with settings re-launcher and Brave auto-bypass.
